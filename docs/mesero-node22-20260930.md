## Compatibilidad y cambios

Puppeteer 25 requiere Node >=22.12 y cambió varias API. Se revisaron sus
consumidores: el generador de cotizaciones ya usa importación ESM y no
necesitó cambios. La prueba nueva `npm run test:runtime` verifica la versión
de Node, las rutas/opciones asíncronas de Puppeteer, el arranque y cierre
del navegador, contexto, DOM y selección con triple clic.

En la prueba CRM se sustituyó la opción retirada `clickCount` por `count`.
Se añadieron barreras para admitir solo PostgreSQL local y bloquear las
peticiones HTTP externas del navegador; el preload local ya protege a Node.
No se cambiaron el HTML ni el comportamiento del panel.

El Dockerfile incorpora `unzip`. Omite **solo** la descarga automática de
Puppeteer durante `npm ci`, instala Chrome explícitamente con la CLI local
de la dependencia fijada y abre/cierra el navegador durante el build.
No omite los scripts de instalación de otras dependencias. Un fallo de
instalación o arranque impide dar por válida la imagen.

## Incidentes encontrados y resueltos durante la verificación

1. El primer build no pudo arrancar Chrome. Puppeteer 25 necesita `unzip`
   (o un extractor opcional); el postinstall no convirtió la descarga
   incompleta en fallo de instalación. La comprobación de arranque sí detuvo
   el build. Se añadió `unzip` y la instalación explícita que falla ante
   errores; el segundo build y el PDF real pasaron sin caché auxiliar.
2. La suite CRM falló 8/10: esperaba `#CRMUI-A-1`/`#CRMUI-A-2`, aunque el
   panel muestra esos folios sin `#`. Se reprodujo el mismo resultado en
   **Node 20.20.2 con la imagen anterior**. Se corrigió la expectativa para
   comprobar el ID completo del tooltip y el texto exacto de cada folio,
   conservando las comprobaciones de canales y estado. Resultado: 10/10.
   No se modificó producción para hacer pasar la prueba.
3. El seed de usuarios no es idempotente: repetirlo sobre la misma base
   devuelve email duplicado. Las comparaciones de navegador se hicieron en
   bases locales separadas con un solo seed; no se alteró ese helper.
